[[proxy-api]]
== Proxy API Endpoints

Proxy endpoints are general-purpose aliases configured in the CMS. They forward requests to target endpoints and inherit their specification. If a `provider` path parameter is present, it is always forwarded to the target endpoint.

[[proxy-endpoint]]
=== General Purpose Proxy

`GET /api/virtual-classes/v4.0/content-providers/{provider}/proxy/{endpoint_name}`

.Request Headers
|===
|Name |Required |Description

|Accept
|Yes
|application/json

|authorization
|Yes
|apiKey {key}

|===

.Path Parameters
|===
|Name |Type |Required |Description

|provider
|String
|Yes
|Association machine name

|endpoint_name
|String
|Yes
|Name of the aliased endpoint (configured in CMS)

|===

.Response

Depends on the CMS-configured target endpoint mapping. See the corresponding endpoint for response structure.

[[top-level-categories]]
=== Top-level Categories

`GET /api/virtual-classes/v4.0/content-providers/{provider}/categories`

Returns the list of top-level categories (programs) for the given provider. "New Videos" and "Around the Y" are excluded from this list.

.Request Headers
|===
|Name |Required |Description

|Accept
|Yes
|application/json

|authorization
|Yes
|apiKey {key}

|===

.Path Parameters
|===
|Name |Type |Required |Description

|provider
|String
|Yes
|Association machine name

|===

.Query Parameters
|===
|Name |Type |Required |Description

|page
|Integer
|No
|0-indexed page number (default: 0)

|limit
|Integer
|No
|Number of items per page (default: 20)

|hidden
|Integer
|No
|Pass any non-zero value to include hidden categories

|===

.Response Fields
|===
|Name |Type |Description

|items
|Array[Object]
|List of category brief objects

|items[].id
|Integer
|Category ID

|items[].name
|String
|Category name

|items[].hidden
|Boolean
|Whether this category is hidden

|items[].parent_program_id
|Integer
|Parent program ID (0 if top-level)

|items[].videoCount
|Integer
|Number of videos in this category

|items[].thumbnail
|String
|Thumbnail URL

|items[].thumbnails
|Object
|Responsive thumbnail variants: `original`, `1920x1080`, `1280x720`, `640x360`, `1920w`, `1280w`, `640w`, `320w`

|items[].premium
|Boolean
|Whether this is a premium category

|items[].circle_icon
|String
|Circle icon URL

|items[].color
|String
|Brand color hex code

|items[].background
|String
|Background image URL

|summary.total
|Integer
|Total number of results

|summary.page
|Integer
|Current page number

|summary.limit
|Integer
|Items per page

|===

[source,json]
----
HTTP/1.1 200 OK
{
  "items": [
    {
      "id": 12,
      "name": "Yoga",
      "hidden": false,
      "parent_program_id": 0,
      "videoCount": 45,
      "thumbnail": "https://example.com/yoga.jpg",
      "thumbnails": {
        "original": "https://example.com/yoga.jpg",
        "1920x1080": "https://example.com/yoga-1920.jpg"
      },
      "premium": false,
      "circle_icon": "https://example.com/yoga-icon.png",
      "color": "#FF5733",
      "background": "https://example.com/yoga-bg.jpg"
    }
  ],
  "summary": {
    "total": 10,
    "page": 0,
    "limit": 20
  }
}
----

|===

|Accept
|Yes
|application/json

|authorization
|Yes
|apiKey {key}

|===

.Path Parameters
|===
|Name |Type |Required |Description

|provider
|String
|Yes
|Association machine name

|===

.Query Parameters
|===
|Name |Type |Required |Description

|searchString
|String
|No
|Full-text search string

|page
|Integer
|No
|0-indexed page number (default: 0)

|limit
|Integer
|No
|Items per page (default: 20)

|sort
|String
|No
|Sort order: `createdAsc`, `createdDesc`, `titleAsc`, `titleDesc`, `instructorAsc`, `instructorDesc`, `locationAsc`, `locationDesc`

|duration[]
|String
|No
|Filter by duration bucket: `short`, `long`, `15m`, `30m`, `45m`, `1h`, `1hplus`

|vids[]
|Integer
|No
|Filter by specific video IDs

|program[]
|Integer
|No
|Filter by program/category ID

|location[]
|String
|No
|Filter by location

|level[]
|String
|No
|Filter by level

|instructor[]
|String
|No
|Filter by instructor name

|instructorId[]
|Integer
|No

|equipment[]
|String
|No

[[vimeo-playback-proxy]]
=== Vimeo Playback Proxy

`GET /api/virtual-classes/v4.0/content-providers/{ls_association_machine_name}/vimeo-playback/{livestream_id}`

Returns a redirect to a fresh signed m3u8 playback URL for a Vimeo-hosted live stream. The signed URL expires; clients must follow this proxy URL each time they need a fresh playback URL rather than caching the redirect target.

.Request Headers
|===
|Name |Required |Description

|Accept
|Yes
|application/json

|authorization
|Yes
|apiKey {key}

|===

.Path Parameters
|===
|Name |Type |Required |Description

|ls_association_machine_name
|String
|Yes
|Association machine name

|livestream_id
|Integer
|Yes
|Live stream node ID

|===

.Response

|===
|Status |Description

|302
|Redirect to a time-limited signed m3u8 playback URL (in the `Location` header)

|404
|Live stream not found, or not a Vimeo-hosted live stream

|401
|Missing or invalid API key

|===

Supports the same filter parameters as <<search-videos>>. Returns only brief video information. Videos from the "Around the Y" virtual category are excluded.

.Request Headers
|===

|Accept
|Yes
|application/json

|authorization
|Yes
|apiKey {key}

|===

.Path Parameters
|===
|Name |Type |Required |Description

|provider
|String
|Yes
|Association machine name

|===

.Query Parameters

Same as <<search-videos>>.

.Response Fields

Same as <<search-videos>>. Additionally:

|===
|Name |Type |Description

|items[].moderation_state
|String
